# وضعیت توسعه

مسیرهای جدید تور و رزرو گروهی، ظرفیت اتمیک، تأیید و رد و لغو و تکمیل، تاریخچه،
نقش‌ها، گزارش، خروجی محدود، پرداخت دستی، شبیه‌ساز پرداخت و صف اعلان پیاده شده‌اند.
راهنمای کامل فارسی در [README.fa.md](../README.fa.md) و قراردادهای دقیق در
[ACCEPTANCE.md](ACCEPTANCE.md) هستند. پیاده‌سازی با موفقیت همه تست‌ها یکی نیست؛
نتیجه واقعی هر Commit باید در GitHub Actions و PR بررسی شود.

Migration شماره ۱ و داده قدیمی حفظ شده‌اند. Migration شماره ۲ جدول‌های محصول
را به‌صورت افزایشی اضافه می‌کند. از عضویت قدیمی، تور یا رزرو فرضی ساخته نمی‌شود.
برای ارتقا، توقف نویسنده‌ها و پشتیبان و تمرین بازیابی لازم است. بازگشت مستقیم
به نسخه قدیمی پس از ثبت داده جدید امن نیست.

PR تا رفع معیارهای پذیرش Draft می‌ماند. پرداخت تجاری، VPS و HTTPS واقعی،
تست زنده تلگرام، تسویه و استرداد واقعی و ابطال Tokenهای قدیمی به دسترسی اپراتور
وابسته‌اند و BLOCKED EXTERNAL هستند. هیچ مقدار Secret بازنشر نشده و هیچ Merge،
استقرار یا پرداخت واقعی انجام نشده است. مجوز GPL-3.0-only حفظ شده است.
